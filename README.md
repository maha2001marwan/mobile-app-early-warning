# AppPulse | منصة تحليل مراجعات التطبيقات والمنافسين

منصة تفاعلية مبنية باستخدام **Streamlit** لتحليل مراجعات تطبيقات Google Play، ومقارنة مؤشرات الشكاوى بين تطبيق رئيسي ومنافسيه، ورصد المراجعات الحرجة. يمكن استخدام نموذج تعلم آلي لتقدير خطورة مراجعة جديدة، وإنشاء تقرير تنفيذي باللغة العربية.



**التطبيق المنشور:** [AppPulse على Streamlit]()  
**مجموعة العرض الافتراضية:** Uber Eats وDoorDash وGrubhub وDeliveroo.

## ما الذي يقدمه التطبيق؟

- البحث عن التطبيقات في Google Play واختيار تطبيق رئيسي ومنافسين للمقارنة.
- جلب أحدث المراجعات المتاحة للتطبيقات المختارة وتنظيف البيانات وتجهيزها للتحليل.
- مقارنة **Logistic Regression** و**Random Forest** باستخدام مقاييس الدقة والإحكام والاستدعاء ومصفوفة الالتباس.
- عرض متوسط التقييم ونسبة المراجعات الحرجة وتوزيع التقييمات وفئات الشكاوى.
- لوحة معلومات محدثة ببطاقات مؤشرات رئيسية وجدول مقارنة مباشر بين التطبيقات.
- تقدير احتمال كون مراجعة جديدة حرجة، مع مستوى خطورة وإجراءات متابعة مقترحة.
- عرض اتجاه الشكاوى حسب الأسبوع ومقارنة آخر سبعة أيام بالفترة السابقة.
- إنشاء تقرير تنفيذي باللغة العربية عند إعداد مفتاح Gemini، أو عرض ملخص محلي عند عدم توفره.
- تنزيل البيانات المعالجة بصيغة CSV والتقرير بصيغة TXT.

تتضمن الأسواق العربية **السعودية والإمارات ومصر والأردن**؛ يطلب التطبيق المراجعات العربية لهذه الأسواق عند توفرها. ويمكن اختيار الأسواق الأخرى لجلب مراجعاتها باللغة الإنجليزية.

## رحلة تحليل البيانات

1. **اختيار السوق والتطبيقات:** تحديد بلد متجر Google Play، والبحث عن التطبيقات، ثم اختيار التطبيق الرئيسي وما بين منافسين اثنين وأربعة.
2. **جمع المراجعات:** جلب المراجعات الأحدث ضمن العدد المحدد لكل تطبيق، ثم دمج النتائج وإزالة المراجعات المكررة أو الفارغة.
3. **تجهيز البيانات:** استخراج ميزات مثل طول النص، وعدد الكلمات، وعلامات التعجب، والإعجابات، وكلمات الأعطال، ونسبة الأحرف الكبيرة، وساعة النشر.
4. **تحديد الفئة المستهدفة:** تُعد المراجعة حرجة إذا كان تقييمها **نجمتين أو أقل**.
5. **تدريب النماذج ومقارنتها:** تقسيم البيانات إلى تدريب واختبار بنسبة 80/20 مع الحفاظ على نسب الفئات، ثم مقارنة النموذجين واختيار الأعلى استدعاءً، والاستعانة بالإحكام لكسر التعادل.
6. **عرض النتائج:** إظهار مؤشرات المقارنة والرسوم، ثم إتاحة تقييم مراجعة جديدة وإنشاء تقرير قابل للتنزيل.

## التقنيات المستخدمة

| المجال | الأدوات |
|---|---|
| واجهة التطبيق | Streamlit |
| جمع المراجعات | `google-play-scraper` |
| معالجة البيانات | pandas وNumPy |
| تعلم الآلة | scikit-learn |
| الرسوم التفاعلية | Plotly |
| التقرير التوليدي الاختياري | Gemini 2.5 Flash عبر `google-genai`، مع نماذج بديلة عند تعذّر توفره |

## متطلبات التشغيل

- Python بإصدار متوافق مع الحزم الموجودة في [`requirements.txt`](./requirements.txt).
- اتصال بالإنترنت للبحث وجلب المراجعات وإنشاء تقرير Gemini.
- مفتاح Gemini API اختياري؛ بقية التحليل لا تتطلبه.

## التشغيل محليًا

افتحي الطرفية في مجلد المشروع ونفّذي:

```bash
python -m venv .venv
```

فعّلي البيئة الافتراضية، ثم ثبّتي الاعتماديات وشغّلي التطبيق:

```bash
pip install -r requirements.txt
streamlit run app.py
```

بعد التشغيل، افتحي عنوان التطبيق المحلي الذي تعرضه Streamlit في الطرفية.

## استخدام التطبيق

1. اختاري بلد متجر Google Play.
2. ابحثي عن التطبيق المطلوب، ثم حدديه كتطبيقك الرئيسي.
3. اختاري من القائمة **منافسين اثنين إلى أربعة**.
4. حددي عدد المراجعات المراد جلبها لكل تطبيق واضغطي **ابدأ التحليل**.
5. استعرضي علامات التبويب:
   - **لوحة المعلومات:** بطاقات مؤشرات الأداء، وجدول مقارنة، ورسوم توضح التقييمات والشكاوى.
   - **مقارنة النماذج:** نتائج النماذج ومصفوفات الالتباس وأهمية الميزات.
   - **تقييم المراجعات:** أدخلي نصًا واحصلي على تقدير الخطورة والتوصيات.
   - **التقرير التنفيذي:** أنشئي التقرير الذكي أو اطلعي على الملخص المحلي.
   - **البيانات:** راجعي البيانات المعالجة ونزّليها بصيغة CSV.
   - **تنبيهات الاتجاهات:** قارني نسبة الشكاوى الحرجة بين الفترات الزمنية.

### كيف تُفهم مقاييس النموذج؟

- **الدقة (Accuracy):** نسبة التوقعات الصحيحة من جميع التوقعات.
- **الإحكام (Precision):** نسبة المراجعات الحرجة الصحيحة من المراجعات التي صنّفها النموذج على أنها حرجة.
- **الاستدعاء (Recall):** نسبة المراجعات الحرجة التي نجح النموذج في اكتشافها من جميع المراجعات الحرجة الفعلية.

يُفضّل التطبيق الاستدعاء عند اختيار النموذج لأن عدم اكتشاف شكوى حرجة قد يكون أكثر كلفة من إرسال إنذار يحتاج إلى مراجعة بشرية.

## إعداد التقرير الذكي

يمكن إنشاء التقرير التنفيذي باستخدام Gemini 2.5 Flash. أضيفي المفتاح إلى أسرار Streamlit أو إلى متغير بيئة باسم `GEMINI_API_KEY`. يحاول التطبيق استخدام نماذج بديلة إذا تعذّر توفر النموذج الأساسي. لا تضعي المفتاح مباشرة في ملفات المشروع أو مستودع GitHub.

مثال على ملف أسرار Streamlit:

```toml
GEMINI_API_KEY = "ضعي_مفتاحك_هنا"
```

إذا لم يتوفر المفتاح أو تعذّر الاتصال بالخدمة، يعرض التطبيق ملخصًا محليًا بدلًا من التقرير التوليدي.

## نشر التطبيق على Streamlit Community Cloud

1. ارفعي ملفات المشروع إلى مستودع GitHub تملكين صلاحية استخدامه.
2. من [Streamlit Community Cloud](https://share.streamlit.io/) أنشئي تطبيقًا جديدًا وحددي المستودع والفرع وملف `app.py`.
3. إذا رغبتِ في تفعيل التقرير الذكي، أضيفي `GEMINI_API_KEY` في إعدادات **Secrets** الخاصة بالتطبيق.
4. ابدئي النشر واختبري البحث وجلب المراجعات والرسوم والتنزيل من الرابط المنشور.

**تنبيه أمني:** لا ترفعي مفاتيح API أو كلمات المرور إلى GitHub. خزّني الأسرار في إعدادات المنصة أو في متغيرات البيئة.

## حدود التحليل والتنبيهات

- تُجلب أحدث المراجعات المتاحة وقت تشغيل التحليل؛ النتائج تمثل هذه العينة وليست بالضرورة كامل مراجعات التطبيق.
- تُحسب الشكوى الحرجة اعتمادًا على التقييم (نجمتان أو أقل)، وليس على حكم بشري لمحتوى كل مراجعة.
- تصنيف فئات الشكوى يعتمد على مطابقة كلمات مفتاحية عربية وإنجليزية؛ لا يمثّل تحليلًا لغويًا شاملًا أو ترجمة آلية.
- يجري تطبيع بعض أشكال الحروف العربية وعلامات التشكيل لتحسين مطابقة الكلمات المفتاحية، لكن اللهجات والتعبيرات غير المدرجة قد لا تُصنّف.
- يبقى نص المراجعة بلغته الأصلية، ولا يترجمه التطبيق تلقائيًا.
- تعرض صفحة الاتجاهات المراجعات الموجودة في مجموعة البيانات الحالية، ولا تحفظ سجلًا تاريخيًا مستقلًا بين مرات تشغيل التطبيق.
- يقارن التنبيه آخر سبعة أيام بالسبعة السابقة، ويحتاج إلى خمس مراجعات على الأقل في كل فترة. يظهر التنبيه عند زيادة نسبة الشكاوى الحرجة بمقدار **10 نقاط مئوية أو أكثر**.
- التنبيه إشارة للمراجعة والمتابعة، وليس اختبارًا للدلالة الإحصائية أو إثباتًا لسبب الزيادة.
- قد تتأثر النتائج بتوفر بيانات Google Play والاتصال والبلد المختار. استخدمي النتائج كمؤشر مساعد، وراجعي المراجعات الأصلية قبل اتخاذ قرار.
